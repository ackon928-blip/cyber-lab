Lesson 1: Introduction to Networking

IP Address

A numerical address used to identify a device on a network.

DNS

DNS translates domain names into IP addresses.

Ports

Ports identify communication endpoints for network services.

Protocols

Rules that allow devices to communicate.

Practice Commands

Check your IP address:

ip addr

Test network connectivity:

ping -c 4 google.com

Display network routes:

ip route
